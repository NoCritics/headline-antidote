# Scraper comparison

Generated by `scraper_comparison/run_comparison.py`. Versions: beautifulsoup4 4.15.0, trafilatura 2.3.1, newspaper4k 0.9.6.1, Playwright driving the installed Google Chrome.

Two guard placements are compared:

- **after**: `guard.analyze(scraped_text)`, the guard only sees what the scraper produced.
- **beside**: `guard.analyze_html(document, "//h1", scraped_text)`, the guard reads the same document as the scraper (raw HTML for HTML parsers, the rendered DOM for browsers) and compares it with the scraper's output.

`MISSED` = the attack reached the scraper's text and the guard said `pass`.

Body-text extractors do not read the headline element, so for them the **beside** guard checks the raw HTML without comparing texts.
